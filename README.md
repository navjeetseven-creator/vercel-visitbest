# VisitBest (Vercel)

Production repository for [visitbest.in](https://visitbest.in).

## Features
- **Bigg Boss Season 20 Voting**: Live audience sentiment tracker, poll leaderboard, nomination status, and eviction updates.
- **Fast Static Delivery**: Optimized for fast global CDN serving via Vercel.
- **Clean URLs**: Pre-configured with clean URLs and trailing slashes via `vercel.json`.
